## Cores e fontes verificadas

O CSS global de Elementor (`global.css`, origem https://macchioengenharia.com.br/wp-content/uploads/elementor/css/post-5.css?ver=1617321393) define Montserrat como família global e botões com fundo #000000, texto #FFFFFF, hover #4F4F4F. O CSS da home (`home.css`, post-4654.css) usa #000422 para título principal, #DBDDEE para divisória, #000000 para seção escura e PT Sans Narrow em headings de apresentação/serviços. O rodapé (`header.css`, post-4655.css) usa fundo #000000, textos #FFFFFF, detalhes #DBDDEE e hover social #414141.

Os tokens Elementor #6EC1E4 e #6181CE permanecem no kit, mas as regras efetivas de botões e seções verificadas são monocromáticas; não há evidência suficiente para tratá-los como cor principal atual da marca.

Montserrat foi obtida pelo CSS oficial do Google Fonts em https://fonts.googleapis.com/css2?family=Montserrat:wght@100..900&display=swap, salvo como montserrat-variable.css. A família é a mesma do site; a distribuição variável foi selecionada para servir o sistema localmente.
